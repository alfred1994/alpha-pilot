## 已修复的主要缺陷

- **风险与账户一致性**：风险 JSON 在跨进程锁内重读和原子替换，损坏时阻断；账户版本校验拒绝旧快照覆盖现金/持仓，成交、投影和账户仍在同一事务内。WAL 初始化和 schema 升级共享初始化锁，常规打开不再全量执行 DDL。
- **交易入口**：手动与自动执行共用暂停/行情门禁，默认纸单要求可验证报价，历史回放显式区分；持仓报价不完整时不改写风控基线并禁买。按已验证价格估值与复评，熔断按交易日计算，共享默认滑点。已知停牌和封板拒绝模拟成交；没有足够板价信息的新买入保守阻断。
- **编排与故障可见性**：复盘按日期原子领取；异常计划和复盘要求核对且不自动重放；救援扫描不覆盖主计划。评分超时、阶段失败和模型超时可见，不因零置信度永久关闭后续 LLM；手动止损失败返回非零退出码。
- **信号与研究数据**：畸形情绪响应置信度归零、技术占位不参与平均、主路径仅用已收盘日线；主要历史数据消费者拒绝陈旧窗口。修正嵌套候选奖励重复、资金三元组解包、历史买卖错误配对，以及少量交易自动晋级永久教训。
- **回测的确定性错误**：参数网格迭代器计数、负回撤排序、同根信号成交、费用方向和滑点已修；研究评分剔除无效维度，样本内优化明确标识用途。
- **看板**：公开 GET 全链路只读；重状态查询有10秒缓存、在途合并和失败退避。真实失败503、非法输入422，历史数据批量查询，公开字段继续脱敏。未知计数保留 null，存储价与实时价区分，抓取时间与底层时间分开。
- **界面**：账户摘要前移，接口不可达不再冒充交易系统故障；补陈旧状态、键盘弹窗、语义化漏斗数字、准确筛选入口、字号/对比度、移动状态、超时恢复与隐藏页轮询控制。无暗色主题属于未承诺的新功能，未加入。

## 纠正的审计结论

- **C14**：滚动训练吸收已经过去的上一折验证段是合法的 walk-forward，不等于向未来泄漏。
- **C16**：最新预测行的目标标签为 NaN，在训练中已剔除；最终 refit 使用已知历史不等于最新预测样本内拟合。
- **C15**：vectorbt 回撤为负数，原 walk-forward 取最大方向正确；真正反向的是参数扫描，已修复。
- **A3**：历史高水位属于历史回撤定义，不能每日清零来弱化风险约束。
- **D6**：WAL 是数据库持久属性，新连接未重复发 PRAGMA 不等于丢失 WAL。
- **B4/B10/C20/E8** 等还有部分夸大或误判：单次扫描身份不应粗暴合并、真实 critical 不应因锁占用而放行、报告已有样本数、生产默认 CORS 并非通配。详见分表。

## 安全降级与保留的研究边界

1. **可转债目前仅观察机会**：当前扫描器没有等价技术/LLM/稳定性证据，缺证据买入已阻断；这不是已完成可转债策略恢复或样本外验证。已有持仓的风险退出仍使用新鲜有量报价；缺板价时明确模拟成交可行性未知。
2. 行业集中度需要可信行业元数据；现有 `Candidate.industry` 不能作为硬门禁依据。跨源逐值对账、复权因子体系、真实排队/部分成交、多策略独立统计验证仍属于后续研究/数据能力，未伪称完成。
3. A/B 信号不等于真实实验成交结果；禁用自动调整时停止创建无效实验。三个回测器仍是研究工具，不代表完整生产 LLM 系统的业绩。
4. `candidate_outcomes` 是业务/训练样本，未因容量推测静默删除。中断领取保留防重证据，不能为了重试删除后重放。
5. 所有性能改善来自本地源码与有界回归；没有生产规模压测，也没有真实账户、付费 LLM 或生产部署验收。
