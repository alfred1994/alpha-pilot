# 固定方向与分散持仓研究候选

后续已加入[可投资ETF对照与低频配置研究](etf-research.md)，区分个股选择和行业配置效果，不把同池股票等权误称为ETF。

`strategy/diversified_research.py` 提供独立研究目标生成器，使用现有共享资金账本；不修改正式策略、调度、LLM 或账户。

相对最初的每5日调仓、5股集中、滚动IC筛选，修订假设为：

- 每20个面板交易日调仓，减轻频繁交易的成本。
- 跳过最近20日的120日动量，预先固定动量方向；不根据短期IC反转方向。
- 可选对60日收益波动率的倒序秩与动量秩等权融合，不加入复杂模型。
- 动量/低波动候选目标20股、单股5%、每个人工行业组最多4股。
- 原目标成员仍在前30名且满足趋势条件时优先保留，减轻排名小幅波动引起的换手。
- 收盘高于MA120且中期动量为正才参与趋势候选；不足名额保留现金，不集中加仓。

排名缓冲跟踪的是历史目标成员，非成交确认的真实持仓；执行失败由原账本保留并记录。行业上限是目标构造上限，旧仓卖出受阻或价格变化可使实际权重偏离。使用共同日期轴、不填未来行情，缺失报价不会被未来恢复交易记录倒填。

## 固定实验

```bash
python scripts/run_strategy_revision.py --input data/reports/kt-sector-20261011/panel.json --output data/reports/strategy-revision-new-run
```

输出目录必须是新目录，禁止覆盖已有manifest。四个预先定义方案全部保留：

|名称|规则|
|---|---|
|monthly_equal|每20日全池等权，无趋势过滤，对照也参与方案选择|
|broad_trend|全池等权加趋势过滤，不合格股票对应份额留现金|
|momentum20|趋势合格股票中按中期动量选择20只，排名缓冲和行业上限|
|balanced20|与momentum20相同，但融合动量和低波动秩|

开发段为2025-05-30至2025-12-31；脚本先物理截断输入，选择“净收益减0.5倍最大回撤绝对值”最大的方案。如果该目标不为正，选择现金。写出 `frozen_selection.json` 后才运行包含2026的回放，并校验完整输入下开发段的信号和净值与截断输入完全一致。

2026已在前次研究中观察过，新的候选设计也受此前结果启发，所以即使程序隔离正确，该段仍不能称为全新的独立样本外测试。最终需要新的市场数据或前向模拟观察，不能重复在这段历史上调到满意为止。

资金默认1000万元，费用、整手、T+1和成交假设与旧实验一致。对冻结方案再做10万元和固定滑点档位敏感性。原版零费用回放用于区分信号与成本问题，不参与方案选择。

原KT输入的当前存续股票池偏差、复权价格模拟整手、缺失日旧价估值、历史ST及公司行动未完整模拟等限制继续适用。该模块仍只用于研究，报告不自动晋级。

## 验证

```bash
python scripts/run_tests.py --run-one tests/test_diversified_research.py
python scripts/run_tests.py --run-one tests/test_factor_research.py
```

覆盖未来数据扰动、截断输入一致性、行业/权重限制、调仓间隔、排名保留、趋势空仓和缺行情不填充。停止调用研究入口即可回滚，无需改变正式交易配置。
