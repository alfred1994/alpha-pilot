# ETF 前向模拟观察

这是独立的日线前向研究实验，不是已有正式模拟账户，也不连接券商、LLM或生产服务。
按 `pilot_driver` 的 paper 边界运行，任何结果都不自动晋级。

## 冻结内容

- 三个实验账户：行业ETF等权（主要观察对象）、趋势过滤、行业轮动。
- 两个外部对照：沪深300ETF、中证500ETF买入持有。
- 每个账户独立10万元，共享的只是行情；不继承旧回测现金、持仓或收益。
- 每20个新行情交易日生成三套规则的新目标，观察60个交易日后停止推进；ETF对照不换策略。
- ETF单边佣金0.03%、最低5元、滑点0.1%，卖出印花税0；整手100份、T+1，价格刻度0.001。
- 使用原始开盘/收盘价格记账；涨跌停以原始前收盘±10%近似，缺乏真实排队/冲击信息，成交只是模拟估计。

历史KT前复权日线只用于形成特征和初始目标；未来账户用新收盘后获取的新浪原始快照记账。
同时保存供应商公司行动事件，发生变化就阻断，以免漏计分红或份额变化。该处理不等于完整分红账务。

## 命令

```bash
python scripts/run_etf_forward.py --init
python scripts/run_etf_forward.py --step
python scripts/run_etf_forward.py --status
```

默认库为 `data/reports/etf-forward-20261012/forward.db`。初始化仅允许创建新文件；状态命令只读且不请求行情。
自定义实验用 `--db` 指定新路径；`--capital` 仅初始化时生效，之后以manifest为准。
初始信号要在下一交易日9:30之前记录，最好盘后或盘前；开盘后才初始化的旧日期信号不能事后成交。

`--step` 应在北京时间交易日16:15左右运行。只接受15:15之后确认的已收盘日线、同日15:00后的完整原始快照。
周末/休市行情不变会返回 `unchanged`。新交易日按此前真实留档的信号模拟当天开盘成交，盘后才能显示结果；这是收盘后模拟结算，不是开盘时下单或真实成交。

## 防止回测伪装成前向结果

1. 信号存入SQLite时保留实际生成时间；数据请求结束后才记时间，不倒签。
2. 只有记录时间严格早于执行日9:30的目标能执行。晚到信号阻断，不追溯使用开盘价。
3. 一次推进只能新增一个行情日期；漏跑多个交易日阻断，不追补不存在的观察或目标。
4. 已保存的原始价格、初始特征历史和目标保持不变。每次重放复用现有受测账本，核对之前逐日净值完全不变。
5. 浮点持久化保留精度；SQLite事务和日期主键保证重复/并发调用不会重复成交。
6. 冻结模块代码指纹；源代码变化、旧复权价格修订、公司行动事件变化或覆盖缺失时非零退出，不自动改规则。
7. 60日结束保留未平仓市值，不虚构卖出或立即升级生产策略。停止调用即停止实验；不自动改生产配置。

发生阻断时先查原因和审计表，不删除实验库、不修改历史目标、不自动重建。需要处理公司行动或修改规则，应明确开新实验版本，保留旧结果。

### KT最新日线精度恢复（2026-10-13修复）

发现KT最新收盘日线可能只有两位小数，次日查询同一日期恢复为三位。仅当旧值精确位于0.01刻度、新值精确位于ETF的0.001刻度、新值等于该日已保存的原始快照，并且按ROUND_HALF_UP舍入为两位后等于旧值，才允许继续观察。不是扩大价格差容忍范围，也不允许三位降为两位或任意小额修订。

接受的差异写入新增观察结果的 `data_precision_audit`，包含日期、代码、旧特征价、新特征价、原始快照价及规则版本。已经保存的特征历史、原始报价、信号和账户结果不覆盖；下一步仍校验历史净值完全一致。公司行动记录变化依然先行阻断。

已初始化实验应用此修复需要用户授权的显式代码指纹迁移：先做SQLite备份与完整性检查，核对其他冻结模块未改变，在 `code_revisions` 保存原/新manifest、逐文件指纹、历史记录摘要与迁移理由，然后仅更新manifest中的代码指纹。日常自动任务不具备自动接受指纹变化的路径。备份和迁移记录位于实验目录的 `precision-fix-20261013/`，保留旧版本供审计；策略参数未改变。

## 结果读取

数据库包含 `manifest`、`signals`、`observations` 三张表；每次观察留存已收盘特征面板、原始快照和各账户完整结果。
`--status` 输出初始留档信息或最新账户净值、仓位、费用和阻断统计。

至少区分收益、最大回撤、平均仓位、换手及相对于两个宽基/行业等权的超额收益。低仓位低回撤不能单独证明择时有效；60日只是初步观察，不足以证明长期盈利。
