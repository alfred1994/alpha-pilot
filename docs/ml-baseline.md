# 随机森林量化研究基线

项目已有技术指标、逐股 LightGBM、pooled ML、模拟执行和 MA/RSI 参数滚动回测。
主交易链路由 LLM 消费信号作决策；原有 `--walk-forward` 评估的是 MA/RSI，
不能代替 ML 模型或 LLM 交易系统的样本外收益验证。

多股票横截面因子筛选、融合选股及共享资金组合回测已由独立的
[`--factor-research` 入口](factor-research.md)提供；本命令继续作为单股随机森林对照。

`--ml-baseline` 将特征、随机森林、时间验证和成本评估串成一个离线实验。
只读本地 `data/quant.db` 的日线，不下载行情、不调用 LLM、不保存或晋级模型，
也不改账户或自动交易配置。继续保持 `BROKER_MODE=paper`。

## 运行

使用现有环境及 `requirements.txt` 中的 pandas、numpy、scikit-learn：

```bash
python main.py --ml-baseline --stocks 600519 --start-date 2021-01-01 --end-date 2025-12-31 --wf-train-days 250 --wf-valid-days 60
```

输出纯 JSON，按股票独立训练、评估；多股票报告不等于组合回测。日期范围包含
60 日特征预热及训练期。默认至少需要 371 根完整日线：59 根预热、250 个训练
候选日、60 个验证日及 2 根标签实现日。数据不足时输出原因并返回非零退出码。
命令不会自动补数据；应先核验并按项目既有数据流程准备日线。

加 `--ml-validation holdout` 可做单次时间留出：只用最前面的训练窗训练一次，
其余样本全部验证，`--wf-valid-days` 此时为最少验证样本数。
默认 `walk_forward` 每 60 个样本日用最近 250 个候选日重新训练一次，尾折可短于 60 日。

## 固定的 14 个特征

| 类别 | 特征 |
| --- | --- |
| 动量（3） | 5/10/20 日收盘收益率 |
| 均线（3） | 收盘价 / MA5、MA20、MA60 - 1 |
| 波动（3） | 布林带宽度（4 × 20 日标准差 / MA20）、ATR14 / 收盘价、20 日收益率标准差 |
| 成交量（1） | 当日量 / 20 日均量 |
| 震荡（4） | RSI14（0–1）、MACD DIF/DEA/柱分别除以收盘价 |

所有特征仅用当日及过去数据，不用全样本标准化、回填未来值或随机切分。
没有证据表明经典指标天然有效；这组指标只是待验证的候选信号。
它使用独立特征版本，保留现有 ML 模型的输入契约。

随机森林固定 100 棵树、最大深度 5、叶子至少 10 个样本、随机种子 42。
训练每折输出树分裂特征重要性；该排名可能偏向某些特征，不表示因果或收益贡献。

## 标签、切分与成交时序

- t 日收盘产生概率，预测 t+1 开盘至 t+2 开盘的收益方向。
- 训练标签的实现日期必须严格早于验证首日，因此剔除训练窗尾部 2 行。
- 默认概率 ≥ 0.55 做多，否则空仓；阈值在实验前固定，不根据验证结果优化。
- t+1 开盘调仓；新买入仓位最早 t+2 开盘卖出。连续持仓和跨折持仓均不重复收费。
- 整段样本外曲线连续复利，期末按最后标签对应的开盘价扣费清仓。

默认单边佣金 0.03%、单边滑点 0.1%、卖出印花税 0.05%，可分别通过
`--ml-commission`、`--ml-slippage`、`--ml-stamp-tax` 指定。整个区间采用固定
费率，不自动重建历史税率变化。日线研究使用可分割份额和全仓/空仓；没有模拟
整手、最低佣金、流动性冲击、涨跌停或停牌无法成交，不能当作执行级收益。

## 如何读报告

- `classification`：整体样本外准确率、平衡准确率、AUC、Brier 分数。
- `prior_baseline`：仅从各折训练段估算上涨频率的常量模型，同一验证区间对照。
- `strategy_net/gross`：扣费/未扣费收益、最大回撤、观测区间 Sharpe、仓位占比与进出次数。
- `buy_hold_net`、`cash_return`：完全相同样本外区间的买入持有及现金对照。
- `folds`：逐折日期、实际训练/验证行数、边界剔除量、分类指标和特征重要性。
- `predictions`：逐日概率、基准概率、仓位及收益标签，可追溯整个评估。
- `input_sha256`：输入日线指纹；配置和模型参数一并记录。

单类验证窗的 AUC、平衡准确率输出 `null`，无收益波动时 Sharpe 为 `null`。
Sharpe 假设每年 252 个观测区间；若日线缺交易日，此年化估计不可靠。
报告始终标为 `research_only`，没有“回测达标即自动上线”的规则。

## 下一步验收

先确认数据来源、复权口径及交易日完整性，按历史时点构造股票池，覆盖退市样本
和不同市场环境，避免拿今天的优胜股票反推历史表现。当前数据库本身不证明这些条件。
程序拒绝乱序、重复、缺失、零量和异常 OHLC；缺少整天记录与复权失真需额外审计。

检查模型是否稳定优于训练频率基准，扣费后是否仍优于现金及买入持有，表现是否
集中在个别窗口，并对费用和阈值做预先约定的敏感性分析。重复看验证结果再调参
会污染验证；应预留未使用的最终测试区间，随后再做长期模拟盘前向观察。
随机森林同样会过拟合，单次高准确率或高收益都不能证明未来盈利。

这一步没有替换正式信号、改调度或部署服务；停止使用该研究命令即可回到原有流程。

