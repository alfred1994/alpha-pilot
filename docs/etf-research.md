冻结规则后的新数据验证见[ETF前向模拟观察](etf-forward.md)，使用独立账户，初始现金不继承回测收益。

当前股票策略尚未证明优于可投资ETF，因此增加独立研究入口：

```bash
python scripts/run_etf_comparison.py --output data/reports/etf-comparison-new-run
```

使用新目录，manifest先于数据和收益评估保存；不覆盖历史报告、不改正式账户或自动交易策略。需要此前固定60股实验的 `strategy-revision-20261011-final/balanced20-full.json`，用于按同样行业权重构造ETF替代组合。

## 数据与成本

- 从KT获取17只固定国内股票ETF的日线，其中2只宽基、15只行业代理；覆盖2024-02-19至2026-10-09，交易起点为2025-05-30。
- KT显式返回qfq的使用供应商前复权序列；只返回day的必须额外查询新浪hfq事件记录。只接受完整、明确的单位复权因子及零累计分红记录；空响应不能当作无分红，出现非单位调整则阻止运行。
- 这一核验是供应商交叉检查，仍不等于按基金公告逐笔审计分红和份额折算。不重复向复权净值增加现金分红，也不声称已经验证精确总回报。
- 国内股票ETF不收股票卖出印花税；模拟单边佣金0.03%、最低5元、滑点0.1%，采用100份整手、T+1和0.001价格刻度。基金管理费已反映在市场价格/基金资产内，不另扣一次。
- 原股票账本默认价格刻度仍为0.01；新增可配置价格刻度避免把低价ETF距涨停0.004元误判为涨停。
- 仍为前复权价格研究成交；涨跌停用前一已知收盘价±10%近似，不模拟排队或容量，不是实盘可实现收益。

## 比较方法

1. 沪深300（510300）、中证500（510500）按相同日期买入持有。
2. 10个人工行业组各10%，组内ETF映射在运行前固定，每20日调仓。
3. 保持此前股票策略每次目标的行业权重和现金比例，换为行业ETF，检查个股组合相对行业代理的表现。
4. 两个固定主动候选：行业趋势过滤、不合格份额留现金；以及趋势合格行业按中期动量选择最多5组、每组20%。

行业代理不是原股票池的精确复制：电子通信映射芯片+通信，能源电力映射能源+电力，有色化工映射有色+化工，基建运输映射基建+运输，各半；证券保险使用证券ETF与证券保险ETF各半，存在证券成分重叠。代码和比例见 `strategy/etf_research.py` 与实验manifest。

选择阶段物理截断至2025-12-31，按“收益-0.5×最大回撤绝对值”在三种行业ETF配置方案中选择；分数不正则现金。冻结后才运行2026数据，并校验之前信号与净值保持不变。宽基ETF始终列为外部对照，没有按结果选一个宽基冒充策略收益。

2026此前已观察多次，不是新独立测试。更低仓位带来的低回撤不直接证明择时能力；必须结合收益和仓位看。保留所有结果和10万元资金、固定滑点敏感性，任何方案均不自动晋级。
