# 市场证据与候选验证看板

## 第一阶段交付

本阶段不改变候选选择、模型判断、买入预算或执行风控。

- 今日页增加「市场温度与证据」卡片：市场识别状态、快照日期、沪深300
  近5/20日涨跌幅、涨跌停数量、炸板率和最高连板。仅显示现有落库指标，
  不生成新的综合温度分；缺失显示未记录，过期指数不显示数值。
- 新增「候选验证」导航及首页快捷入口：日期和拒绝阶段筛选、稳定分页、
  观察次数、独立股票数、记录模型动作数、T+5回填覆盖。
- 按拒绝阶段展示样本规模、T+5多头观察均值及正收益占比；展开候选可查看
  当时维度分数/置信度、扫描标识、策略版本、价格来源、费用假设和回填时间。
- 接口或存储不可用显示未知，不当作零收益或零候选。

## 数据接口与边界

- GET `/api/research/market`
- GET `/api/research/candidates?start_date=YYYY-MM-DD&end_date=YYYY-MM-DD&layer=llm&page=1&limit=20`

候选默认最近30个日历日。最长367天，单页最多50条，页码最多100000。
汇总统计整个筛选范围，不仅是当前页。读取 SQLite 使用 mode=ro 和
query_only，不通过 Database 初始化，不创建文件、不迁移、不触发外部行情
请求、模型调用、回填或交易。只开放 GET；生产控制API策略保持不变。
公开输出使用字段白名单和文本脱敏，前端动态内容使用 textContent。

重要口径：

1. 候选仅包含已保存有效价格的扫描样本，不代表全市场或全部模型调用。
2. 同一股票多轮观察会重复计入均值；独立股票数另列，不声称样本相互独立。
3. T+N沿用现有回填口径，即观察日后N根已落库日线。停牌或缺失日线会影响
   覆盖，空值只表示未成熟或未回填，不按零收益计入统计。
4. 结果是扣除记录费用及双边滑点的多头观察收益，不是模拟账户成交收益，
   也不是SELL策略的收益。未做基准调整，不称为超额收益或交易胜率。
5. 市场快照日期新，不保证各来源新鲜。过期标记沿用一天日历窗口，非完整
   交易日历判断，周末/节假日可能提示旧快照。
6. 未记录题材热度、候选行业/真实来源快照，因此本阶段没有热题材覆盖率。
   scan_rank_*只是扫描序号，不能伪装为候选的选股来源。

## 第二阶段：独立收益表现页

新增「收益表现」导航，本周/本月/今年快捷区间及自定义起止日期。
指标、两张图和每日明细共用一个区间。接口为 GET
`/api/research/returns?start_date=YYYY-MM-DD&end_date=YYYY-MM-DD`。

- 读取SQLite review_snapshots的日终资产，不请求实时账户、不回填历史。
- 使用区间内第一个和最后一个有效快照，页面明确显示实际日期，
  不假定本月首个快照就是上月底收盘。首条资产变化为未知而非零。
- 展示期初/期末资产、区间资产变化率、同期沪深300、相对变化差、
  日终资产最大回撤，以及逐快照资产变化柱状图和日期明细。
- 未有完整资金流账本，因此所有账户指标标明未调整出入金，不能当作
  已核实投资收益。初始资金发生变化时提示疑似重置，停止账户收益比较。
- 基准只使用k_daily中000300.SH的同日期收盘价，起点归一化为0%。
  不使用旧复盘中可能沿用上一日的benchmark_pnl_pct；缺失点断线，
  起止基准缺失则不展示同期涨幅或相对变化差，真实0%仍正常显示。
- 日线缺日不补造；逐行变化明确显示对比快照日期，不能冒充单日盈亏。
  无效资产快照导致相邻变化不可用，区间内有无效快照时不展示最大回撤。
- 少于两个有效快照不计算区间变化率。资产归零按完整损失处理，
  不当作缺失；未显示年化、夏普和净入金等缺少可靠口径的指标。
- 新请求开始清除旧结果；迟到响应不能覆盖最新区间。全局状态接口失败
  不阻断本页读取。生产只读约束保持不变。

第二阶段验证：新增8项离线HTTP测试，全量pytest为221 passed、4条既有
