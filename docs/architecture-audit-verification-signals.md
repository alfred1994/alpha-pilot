# 架构审计 C 域逐项核验（2026-09-28）

范围：`docs/architecture-audit-2026-09-28.md` 的 C1–C23。依据是当前工作树源码及离线测试；未调用行情、LLM、真实账户，也未对参数优势做样本外实证。本文状态指**源码核验**，不代表生产部署或交易效果。

| 条目 | 核验 | 证据与处理 |
|---|---|---|
| C1 | 主路径成立，具体“完全无护栏”夸大 | 可转债订单在股票选择之后追加，绕过股票技术分、LLM、top_k 门；仍有自身止损/仓位限制。编排层由负责该文件的代理处理；手调权重有无优势仍待独立样本外研究。 |
| C2 | 成立，已修 | `sentiment_signal` 曾对非空畸形响应给 0.7 置信度。现在完整校验 score/direction 并对失败设 0，综合权重自动剔除。 |
| C3 | 成立，编排层处理 | `pipeline` 技术评分仍可能读取当日未完成 bar；该入口由编排代理修，当前文件外的技术信号不会再通过零置信度占位稀释均值。 |
| C4 | 部分成立 | 多套研究入口并存，生产股票 BUY 依赖 LLM；LLM 失败 HOLD 是安全的 fail closed。没有证据支持自动评分回退买入，未引入。研究入口增加与生产系统不同的说明。 |
| C5 | 成立，执行层处理 | paper 与反事实滑点口径曾不同；共享 `PAPER_SLIPPAGE_RATE` 默认 0.0005，执行层及评估成本接线由其负责。 |
| C6 | 成立，已修 | 原 3/3 可成无到期长期记忆。决策模式改为带有效期的“待验证观察”，Wilson 下界约束小样本权重；已有长期决策模式在正常整合时停用，保留记录审计。 |
| C7 | 成立，已修 | 无 `trade_id` 时曾取任意最近买卖。历史回退现在要求买入在决策之后同日发生，卖出在该买入之后且下一次买入之前；无法唯一匹配保持 pending。 |
| C8 | 成立，已修标识 | 东财接口 `HOLD_MARKET_CAP` 是季度持仓市值，不能称资金净流入。候选来源显示“北向季度持仓”；`north_flow` 字段暂保留兼容，注释标明真实单位和含义。其预测价值未验证。 |
| C9 | 成立，已修 | 低位内层、股票外层各给多源奖励。合并记录未封顶基础分以避免重复奖励和 100 分封顶丢失贡献，并复制输出对象避免改写输入；覆盖嵌套饱和和重复对象测试。 |
| C10 | 门槛与奖励机制成立；结果推断未证实 | `PICKER_MIN_SCORE=20` 与每新增来源 +10 属现行参数；“实质只按来源数排名”需要候选分布和样本外结果证明，未任意调参。 |
| C11 | 成立，已修客观错误 | 研究用 `strategy/backtest.py` 原以信号日收盘成交、零成本，且“总收益”实际是逐笔均值。现以前一日数据产信号、次日开盘成交，计佣金/最低佣金/卖出印花税/模拟滑点及整手；报告标明平均每笔净收益、逐笔复利序列回撤非组合净值。 |
| C12 | 成立为方法边界，已标识 | optimizer 仍是在同一区间选参数；明确返回 `evaluation_scope=in_sample_research`、`validated_out_of_sample=False`，报告警示，并重置每次运行历史。未凭任意 holdout 比例宣称优化有效。 |
| C13 | 成立为方法边界，附带真错误已修 | 网格仍是样本内研究，报告引导独立 walk-forward。额外发现 `len(itertools.product(...))` 会直接 TypeError，现按各轴长度乘积统计。无需替用户指定多重检验标准。 |
| C14 | **不成立** | 每折训练区间止于该折验证开始前；前一折验证数据随后变为已知历史，供后一折重新选参是正常 walk-forward。离线测试断言每折 `train_end < valid_start`，且允许历史窗口重叠。仅单折时结论薄弱，但不是泄漏。 |
| C15 | **审计归因反向**，真实相关错误已修 | vectorbt `max_drawdown()` 返回非正值，walk-forward 原取数值最大等于选最小回撤；parameter sweep 原升序反而选最大回撤。现在按 `-abs(drawdown)` 统一比较正/负回撤，并保留总收益次序。 |
| C16 | **不成立** | `build_target` 将末根 bar 标签显式置 NaN，逐股训练 `valid_mask` 对 target 做 `notna()`，pooled `_load_rows` 同样剔除；预测使用末根有特征的 bar。离线假模型断言最新特征行不存在于最终 refit 输入。过去验证段进入最终 refit 是上线前使用已知历史，验证指标仍来自先前隔离段。 |
| C17 | 成立，已修 | 两个决策入口改共用 `_technical_dimension`，仅正置信度且有限分数的子信号参与均值；不可用详情仍供审计。 |
| C18 | 事实成立，但不直接构成缺陷 | `market_mood_signal` 是全市场共同因子，同日不同股票分数相同属设计属性。是否应降低权重需样本外证据，未任意修改。 |
| C19 | 主要差异成立，已修直接可证错误 | 三种回测仍服务不同研究目标，不能当作生产 LLM 交易收益。fast 研究回测改下一根 bar 成交、买卖分别收佣金和卖出印花税、共享滑点；portfolio 研究评分剔除零置信度占位。未做统一交易引擎大重构。 |
| C20 | **部分不成立** | `portfolio/report.py`、`review/performance.py` 已显示总交易次数及胜负次数；`review/ai_trader_report.py` 有 `trade_count`。A/B 只有信号记录而无成交 SELL 回填、影子样本重叠等限制成立；关闭生产 `apply_adjustments=False` 时持续新增 A/B 实验，避免积累无效实验。 |
| C21 | 成立，属于已有优点 | pooled ML、反事实成熟窗口、形态日线截断等守卫保留；其覆盖范围需与生产链路分别看。 |
| C22 | 混合项：两处代码缺陷已修，其余按证据保留 | 缓存决策资金三元组现正确解包；影子重算采用有效维度权重；未使用的前视 `chikou` 变量移除；信号模块注释改为当前配置权重。指令“supported”主观判断、四处阈值、市况回退和模型特征有效性需要政策/样本外证据，不擅自改买入门槛或模型。技术稳定性项需结合编排层日线截断核验。 |

## C22 合并条目的逐项补充核验

| 子项 | 核实及处理 |
|---|---|
| 未使用的 `chikou=shift(-displacement)` | 未接评分，不能据此声称实际前视；已移除这个未使用变量，现用过去价格的迟行线计算保留。 |
| HVN 未用、LVN 只写说明 | 成立为维护问题。LVN 文本可能为 LLM 提供上下文，不影响分数本身不等于错误；不擅自添加方向加分。注释“增加置信度”与固定 conf 不一致应按现状说明。 |
| 资金三元组误用 | 成立，已修正确解包分数、置信度与说明，新增回归。 |
| 稳定性两轮观察 | 技术日线同日稳定成立，但 `observe` 接收的是 composite，含其它可变化维度；这只是连续扫描门槛，不是独立样本的统计确认。不把固定技术分重复读当样本外证据，也不无依据删已有开仓纪律。 |
| 影子维度过滤不同 | 成立，已复用有效维度权重，不再纳入 confidence=0。 |
| 指令 supported 自证、重读不带 current_params | 事实成立为自主策略的证据限制。数值硬上下界独立执行，`inconclusive` 限制在生成时对当前策略执行；重读的是已规范保存的参数。尚无独立统计验证来证明 supported，不将它称为模型已获客观验证；未自行增加需人工批准的每日策略队列。 |
| 四处买入门槛 | 不同层分别是候选综合分、技术门槛、研究决策阈值和市况配置，并非同一参数必然冲突。保留语义差异，实际阈值以调用链为准。 |
| 数字字面量都应 env 化 | 配置文件中的常量本身就是配置；字面量数量不是缺陷证据。未把算法常数机械迁到环境变量，避免扩大非受控运行配置面。共享滑点作为本次确需跨引擎一致的参数已提取。 |
| signals 权重注释错误 | 成立，已去掉过期比例，说明以当前配置为准。 |
| dual_style 仅用于研究脚本 | 调用范围属实；其研究 CLI 用途不等于生产死代码，未删除研究能力。 |
| regime 过期/读取失败静默 | 成立，编排代理已补日期、置信度0和错误记录。 |
| AUC 0.52 与原始价格特征 | 阈值和特征事实成立；“与抛硬币不可区分”“必然偏好低价股”需要验证样本量、置信区间和特征分析，源码不能证明。pooled 另有 balanced accuracy、Brier、baseline gain 和样本覆盖门；未凭猜测替换模型或改变权重。 |
| 禁用自动调整仍创建 A/B | 成立，已使 `apply_adjustments=False` 的观察模式停止创建新实验；有记录不等于有成熟成交实验。 |

原报告 C16 的“单一全局 validation_auc”也不能概括全部 ML：逐股模型缓存按 code/训练窗/最后日期分开，置信度取逐股隔离验证；pooled 的共享指标表示模型级验证质量，而非每只股票的校准概率。
