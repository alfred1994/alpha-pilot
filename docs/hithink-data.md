# 同花顺 Fuyao 研究数据接入

在私有环境中配置 `HITHINK_ENABLED=1` 和 `HITHINK_FINANCE_API_KEY`（兼容 `FUYAO_API_KEY`）。默认关闭；缺少 key 不向此服务发请求。密钥不得提交仓库或填入公共页面。

## 已连接的调用链

- `data.history.get_daily` 的简单字段模式：SQLite → 同花顺 → 长桥 → Baostock → 明确标记的过期缓存。完整字段模式仍由 Baostock 提供，同花顺日线不伪造历史 PE/PB。
- 日线统一成交量为股、成交额为元，支持前复权/后复权/不复权；共享 `k_daily` 没有复权主键，因此仅前复权读写共享缓存。历史既存缓存未进行审计或迁移。
- `refresh_research_universe` 使用全市场快照按成交额筛选：门槛3000万元，沿用普通A股与排除北交所/科创板等限制。每页100，默认最多60页（可用 `HITHINK_UNIVERSE_MAX_PAGES` 设置1～100），由客户端串行节流，只在盘后研究任务运行。分页失败或预算内未完成全市场覆盖就退回原股票池来源，不用部分页面冒充全市场排名。快照未提供名称时保留代码，不能据此认定已排除ST。
- 不自动下载十年全市场大文件；不将新财报直接用于交易权重；不替代KT分钟线及盘口。

## 财务研究命令

```bash
python -m data.hithink_research --stocks 600519,000001 --as-of 2026-09-08
```

该命令最多20只，顺序获取三张报表的最近20期，严格保留 `report_date_ms`（披露日）及 `period_end_ms` 在上海时区指定日结束前的数据，并明确记录缺失。`as_of` 是盘后语义，不能用于当天盘中回测；历史覆盖可能不足，历史修订版本也未经验证，不能据此承诺严格的历史可见性重建。最新估值仅在查询今天时调用；历史日期显式返回不支持历史估值，不把当前PE/PB写入过去。

## 使用限制与验证

[官方文档](https://fuyao.aicubes.cn/llms-full.txt)公开说明当前不限制累计调用次数，但未公布固定QPS、并发额度、价格表或永久免费承诺；账号可能需要权限。客户端串行节流及有限重试只是本项目保守设置，不是官方配额。HTTP 429和业务码4001按有限退避处理，权限或其他异常交由上层降级。

快照时间是整批最新上游时间，不能证明每只股票均新鲜，因此此次没有接入实时交易执行价格。日线/财务来源的完整性、账号权限、盘中延迟、持续稳定性须使用已授权key另行验证。离线契约测试通过不代表真实API或线上验收通过。

回滚：设 `HITHINK_ENABLED=0` 恢复原有获取顺序；若需要清除来源数据，应先备份并另行审查缓存，关闭开关不会自动删除历史研究数据。保持 `BROKER_MODE=paper`。

Windows 研究锁通过 `OpenProcess` 与零等待查询检查持有者，不使用会触发 Ctrl+C 的 `os.kill(pid, 0)`；访问权限不足时保留锁。可运行 `python tests/test_research_lock.py` 和 `python tests/test_research_universe.py` 验证当前进程锁、子进程退出及过期锁回收。
