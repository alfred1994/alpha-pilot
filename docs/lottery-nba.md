# 体彩 NBA 纸面验证模块

来源：`idea2project/projects/nba-prediction-lab`（2026-10-26 立项）。本模块把其中仍有理论依据的部分迁入 AlphaPilot，作为看板的第二个板块。

## 结论先行

- **模型预测已被否决**：16,396 场滚动样本外回测，对盘命中率 49.73%；竞彩 1.70 赔率保本需 58.82%。本模块不再运行模型，历史模型注单以“模型对照组（已停用）”保留。
- **只验证一件事**：竞彩让分/总分比国际盘口更有利时，按竞彩价格买入，长期能否跑赢约 15% 的抽水。这是“买得更便宜”，不是“猜得更准”。
- **纸面记录，不下单**：不代购、不荐彩、不对接境外平台；公开看板在开赛前不展示任何选边。

## 信号与门槛

```
让分偏离 d = 竞彩主队让分 - 国际主队让分        d>0 → 主队一侧更便宜
总分偏离 d = 国际总分 - 竞彩总分                d>0 → 买大更便宜，反之买小
估算胜率 p = 点值表(|d|)                         见 lottery/signals.py
期望值   EV = p × (赔率 - 1) - (1 - p)
入选：EV ≥ LOTTERY_MIN_EV（默认 +2%）且 |d| ≤ 8 分；全天按 EV 取前 3 注，每注 1 单位 = 1% 本金
```

点值表用 19,385 场 SBR 历史收盘线实测（`scripts/lottery_calibrate.py` 可复现）：拿到比收盘线好 3 分的让分，赢盘率约 60%；同样 3 分的总分只有约 56.5%（总分残差标准差 17.7，比分差的 12.2 大）。因此 1.70 赔率下：

| 玩法 | 所需偏离 |
|---|---|
| 让分 | 约 2.8 分 |
| 大小分 | 约 4.4 分 |

与原项目相比的修正：

1. 阈值随实际赔率变化（1.65 与 1.81 的保本线差 5 个百分点），不再统一 2.5 分。
2. 大小分阈值提高。原项目同样用 2.5 分，估算胜率只有约 55.5%，低于保本线。
3. 原项目大小分偏离的方向写反了（竞彩总分高于国际线时应买小），已修正；原账本里没有因此产生的注单。
4. 串关的单场保本命中率仍是 1/赔率，串关只放大方差，不会“吃掉”正期望；账本按单场口径统计，同时记录单关是否开售。

## 运行

| 任务 | 时间（北京） | 内容 |
|---|---|---|
| `alpha-pilot-lottery-picks.timer` | 每天 21:40 | 抓竞彩让分/大小分与 ESPN 国际线，追加快照；销售截止前按信号记录纸面注单（每场每玩法只记第一次，之后不改写） |
| `alpha-pilot-lottery-capture.timer` | 23:30 至次日 14:30 每 30 分钟 | 抓开赛前最后一次国际线作为收盘线近似，补比分，结算注单并计算收盘价差 |

命令：

```bash
python main.py --lottery-picks [--lottery-date YYYY-MM-DD]
python main.py --lottery-capture [--lottery-date YYYY-MM-DD]
python main.py --lottery-import /path/to/ledger.csv   # 导入原项目账本，可重复执行
```

数据库：`data/lottery.db`（`LOTTERY_DB` 可覆盖），与交易主库分离；表 `snapshots`、`games`、`picks`、`runs`。

## 看板

左侧导航分为“股票”和“体彩 · NBA 纸面验证”两组。体彩组有四个页面：

- **验证总览**：已结算注单、命中率与 95% 置信区间、累计盈亏与收益率、平均收盘价差；预注册停机规则进度（50 注命中率 < 55%、150 注收益率 < -5%、回撤 20 注）；累计盈亏曲线与分策略分玩法对照表。
- **场次盘口**：按销售日列出竞彩与国际盘口、单关开售状态、比分；偏离、估算胜率、期望值与纸面注单在开赛后公开。
- **验证账本**：全部已公开注单，可按策略、玩法筛选。
- **方法与数据**：回测结论、边界说明、任务运行与数据源状态。

接口（只读）：`/api/lottery/summary`、`/api/lottery/games`、`/api/lottery/ledger`、`/api/lottery/health`。

## 已知局限

- 国际盘口来自 ESPN 计分板内嵌的单家博彩公司（通常为 DraftKings）快照，不是 Pinnacle 或交易所收盘价；点值表衡量的是相对收盘线的价值，所以门槛留了 +2% 期望值的余量。
- 竞彩数据抓取 500.com 页面，每次任务 2 个请求、每天约 30 次，控频自用；页面结构变化会导致当天无数据（健康页可见）。
- 样本少：按历史频率，偏离信号大约覆盖 6% 的场次；50 注约需 2–3 个月，150 注接近一个赛季。

## 回滚

```bash
systemctl --user disable --now alpha-pilot-lottery-picks.timer alpha-pilot-lottery-capture.timer
```

看板接口在数据库不存在时返回“尚未生成”，不影响股票板块；删除 `data/lottery.db` 即清空纸面账本。
