# 体彩 NBA 纸面验证模块

来源：`idea2project/projects/nba-prediction-lab`（2026-10-26 立项）。本模块把其中仍有理论依据的部分迁入 AlphaPilot，作为看板的第二个板块。

## 结论先行

- **模型预测已被否决**：16,396 场滚动样本外回测，对盘命中率 49.73%；竞彩 1.70 赔率保本需 58.82%。本模块不再运行模型，历史模型注单以“模型对照组（已停用）”保留。
- **只验证一件事**：竞彩让分/总分比国际盘口更有利时，按竞彩价格买入，长期能否跑赢约 15% 的抽水。这是“买得更便宜”，不是“猜得更准”。
- **纸面记录，不下单**：不代购、不对接境外平台。纸面选择在出单时即在公开看板展示（2026-11-02 起，此前开赛后才公开），不构成投注建议。
- **全场预测（每场必出）**：2026-11-02 起，每场比赛的让分、大小分各给一个选择，不设期望值门槛，作为独立策略 `all_games` 统计，不混入主信号。
- **竞彩出票即锁定价格**：竞彩是固定奖金，让分数、预设总分与 SP 以出票时为准。国际盘口只用来衡量竞彩价格是否划算；出票后才公布的伤停只会是风险，无法再调整。
- **竞彩跟踪、伤停标签与停售前影子（2026-11-02 起）**：16:00 出单后每 30 分钟重新抓竞彩到停售，看竞彩是否、何时调线；出单时记录双方伤停名单与标签；停售前最后一次跟踪时按主信号同一规则出影子单 `sharp_late`，用来决定出单时点。三者都只记录、对照，不改变主信号。

## 信号与门槛

```
让分偏离 d = 竞彩主队让分 - 国际主队让分        d>0 → 主队一侧更便宜
总分偏离 d = 国际总分 - 竞彩总分                d>0 → 买大更便宜，反之买小
估算胜率 p = 点值表(|d|)                         见 lottery/signals.py
期望值   EV = p × (赔率 - 1) - (1 - p)
入选：EV ≥ LOTTERY_MIN_EV（默认 +2%）且 |d| ≤ 8 分；全天按 EV 取前 3 注，每注 1 单位 = 1% 本金
```

全场预测（`all_games`）：

```
每场每玩法：用点值表估算两侧胜率（第一侧 p，另一侧 1-p），按竞彩各自赔率算 EV，选 EV 更高的一侧
偏离为 0：两侧胜率约 50%，选赔率更高的一侧
缺国际线：无法估算胜率，选赔率更高的一侧，胜率与期望值留空
竞彩未开售该玩法：跳过
```

按 15% 抽水，偏离很小的场次期望值约为 -5% 到 -10%。这组记录回答的是"每场都买"的长期结果，用来对照主信号是否真的有筛选价值。

点值表用 19,385 场 SBR 历史收盘线实测（`scripts/lottery_calibrate.py` 可复现）：拿到比收盘线好 3 分的让分，赢盘率约 60%；同样 3 分的总分只有约 56.5%（总分残差标准差 17.7，比分差的 12.2 大）。因此 1.70 赔率下：

| 玩法 | 所需偏离 |
|---|---|
| 让分 | 约 2.8 分 |
| 大小分 | 约 4.4 分 |

与原项目相比的修正：

1. 阈值随实际赔率变化（1.65 与 1.81 的保本线差 5 个百分点），不再统一 2.5 分。
2. 大小分阈值提高。原项目同样用 2.5 分，估算胜率只有约 55.5%，低于保本线。
3. 原项目大小分偏离的方向写反了（竞彩总分高于国际线时应买小），已修正；原账本里没有因此产生的注单。
4. 串关的单场保本命中率仍是 1/赔率，串关只放大方差，不会“吃掉”正期望；账本按单场口径统计，同时记录单关是否开售。

## 竞彩跟踪、伤停与出单时点

时间关系（11 月，美东 = 北京 - 13 小时；北京 D 日销售的场次在美国 D 日晚上开打）：

| 事件 | 北京时间 |
|---|---|
| 联盟要求的赛前一天伤停申报（美东 17:00） | D 日 06:00 |
| 主信号与全场预测出单 | D 日 16:00 |
| 竞彩停售（以 `games.buy_end` 为准，实测周日场次为 D 日 23:00） | D 日晚上 |
| 比赛日伤停更新、出战成疑球员最终状态 | D+1 日 00:00–08:00 |
| 开赛 | D+1 日早上 |

所以比赛日的伤停变化基本都落在竞彩停售之后，竞彩买家无法利用，只承担风险。

**竞彩跟踪**：采集任务在竞彩仍销售的场次上重新抓竞彩让分与大小分（快照 `source='track'`，同一时刻的国际线一并写入），距上次竞彩抓取不足 10 分钟时跳过。场次页把出单时的竞彩线和最新一次跟踪并列显示，展开可看完整时间线；“方法与数据”页统计近 30 天竞彩在 16:00 之后线/SP 变动的场次数、首次变线的中位时间，以及与国际线的偏离是缩小还是扩大。

**伤停名单**：来源是 ESPN 伤停接口（汇总自球队与联盟伤停报告）。出单与采集时各抓一次（采集只在还有未开赛场次时抓），每支球队的名单（球员、状态、部位）有变化才追加一条到 `injury_reports`。每条新注单写入：

- `injury_tags`：`24小时内伤停更新`（双方任一条目在出单前 24 小时内有更新，ESPN 改写备注也会刷新时间，口径偏宽）、`有出战成疑球员`（双方有状态不是缺阵/停赛的球员）；空字符串表示两个标签都不满足；`NULL` 表示伤停不可用或是标签上线前的注单，统计时单独计数，不当作“无伤停”。
- `injury_detail`：出单时双方名单（JSON）。

标签不参与选单，只在总览页的“伤停分组对照”里比较有无标签时的命中率、收益率与收盘价差。目前没有球员重要性数据，“主力缺阵”需要人工看名单判断。

**停售前影子 `sharp_late`**：与主信号同一规则（期望值门槛、偏离上限、每日最多 3 注），在竞彩停售前 `LOTTERY_LATE_WINDOW_MINUTES`（默认 45）分钟内的跟踪时出单，每场每玩法只记第一次。它和 16:00 的主信号分开统计；两边的收盘价差对比积累足够样本后，再决定是否把主信号挪到停售前。

## 运行

| 任务 | 时间（北京） | 内容 |
|---|---|---|
| `alpha-pilot-lottery-picks.timer` | 每天 16:00 | 抓竞彩让分/大小分、ESPN 国际线与伤停名单，追加快照；对仍在销售的场次记录主信号注单与全场预测（每场每玩法每策略只记第一次，之后不改写），附伤停标签，记录后立即公开 |
| `alpha-pilot-lottery-capture.timer` | 16:00 至次日 14:30 每 30 分钟（15:xx 不跑） | 停售前跟踪竞彩并在最后窗口记录 `sharp_late`；同步伤停名单；抓开赛前最后一次国际线作为收盘线近似，补比分，结算注单并计算收盘价差 |

命令：

```bash
python main.py --lottery-picks [--lottery-date YYYY-MM-DD]
python main.py --lottery-capture [--lottery-date YYYY-MM-DD]
python main.py --lottery-import /path/to/ledger.csv   # 导入原项目账本，可重复执行
```

数据库：`data/lottery.db`（`LOTTERY_DB` 可覆盖），与交易主库分离；表 `snapshots`、`games`、`picks`、`injury_reports`、`runs`。`picks` 的 `injury_tags`、`injury_detail` 两列在任务首次连接时自动补上（`ALTER TABLE ADD COLUMN`，旧注单为 `NULL`）。

## 看板

左侧导航分为“股票”和“体彩 · NBA 纸面验证”两组。体彩组有四个页面：

- **验证总览**：已结算注单、命中率与 95% 置信区间、累计盈亏与收益率、平均收盘价差；预注册停机规则进度（50 注命中率 < 55%、150 注收益率 < -5%、回撤 20 注）；累计盈亏曲线、分策略分玩法对照表，以及按伤停标签分组的对照表。
- **场次盘口**：按销售日列出竞彩停售时间、竞彩（出单时 → 最新跟踪）与国际盘口、单关开售状态、比分、偏离、估算胜率、期望值和各策略的纸面选择；每场可展开盘口时间线与双方伤停（出单时名单与之后的变化）。
- **验证账本**：全部纸面注单（出单即可见），可按策略、玩法筛选，显示出单时的伤停标签。
- **方法与数据**：回测结论、边界说明、任务运行与数据源状态、近 30 天竞彩调线统计、伤停名单记录状态。

接口（只读）：`/api/lottery/summary`、`/api/lottery/games`、`/api/lottery/ledger`、`/api/lottery/health`。

## 已知局限

- 国际盘口来自 ESPN 计分板内嵌的单家博彩公司（通常为 DraftKings）快照，不是 Pinnacle 或交易所收盘价；点值表衡量的是相对收盘线的价值，所以门槛留了 +2% 期望值的余量。
- 16:00（美东凌晨 3–4 点）出单比原来的 21:40 更早：国际线离收盘更远、噪声更大，个别场次可能还没挂出国际线（主信号跳过该场，全场预测按赔率记录）。
- 竞彩数据抓取 500.com 页面，出单 2 个请求，停售前每 30 分钟跟踪再 2 个请求（每天约 16–30 次），控频自用；页面结构变化会导致当天无数据（健康页可见），跟踪失败不影响收盘线与结算。
- 伤停名单来自 ESPN 非官方接口，结构可能变化；抓取失败时注单的伤停字段为 `NULL`，不影响出单。
- 样本少：按历史频率，偏离信号大约覆盖 6% 的场次；50 注约需 2–3 个月，150 注接近一个赛季。

## 回滚

```bash
systemctl --user disable --now alpha-pilot-lottery-picks.timer alpha-pilot-lottery-capture.timer
```

只回滚竞彩跟踪、伤停与影子单：回退对应提交并重新部署即可；新增的 `injury_reports` 表、`track` 快照、`sharp_late` 注单和两列伤停字段留在库里不影响旧代码读取（旧代码不查询它们）。
