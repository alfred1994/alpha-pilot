# 多因子研究闭环

原始14因子策略的跨行业测试未显示稳定优势；后续[固定方向、分散持仓修订实验](strategy-revision.md)提供独立对照，不自动替换本入口。

入口 `--factor-research` 已连接：

**历史股票面板 → 因子计算 → 训练期检验/去冗余 → 横截面融合排名 → 目标组合 → 次日开盘模拟执行 → 样本外报告 → 下一窗口重新检验。**

这是本地研究闭环，不连接 Broker、不修改正式模拟账户或自动交易参数。
默认 `BROKER_MODE=paper` 保持不变。报告不能直接作为策略上线或盈利证明。
已有 `--ml-baseline` 保留为单股随机森林对照；这里先采用可解释的 RankIC 加权或方向校正等权融合。

## 运行入口

只读本地 `k_daily`，不会触发数据库迁移、行情补齐或 LLM 请求：

```bash
python main.py --factor-research --stocks 600519 000001 600036 601318 000858 --start-date 2021-01-01 --end-date 2025-12-31 --wf-train-days 250 --wf-valid-days 60 --factor-top-k 5 --factor-rebalance-days 5 --factor-report data/reports/factor-strict-2021-2025.json
```

上面的代码只是股票池格式示例，不是推荐股票，也不表示本地已备齐这些数据。
至少需要 5 只股票在相同日期有完整因子，默认需要约 371 个面板交易日覆盖预热、训练、验证及次日执行；停牌或历史不足会增加实际所需跨度。
显式选择的股票若缺数据，会报错；不会静默删掉缺数据股票来美化结果。

也可导入 JSON 历史面板：

```bash
python main.py --factor-research --factor-input historical-panel.json --start-date 2021-01-01 --end-date 2025-12-31 --factor-report data/reports/factor-panel-run1.json
```

JSON 顶层可为行数组或 `{"bars": [...]}`；股票代码须保存为 6 位字符串。
输入仍受 `--start-date/--end-date` 限制；报告使用新文件，禁止覆盖已有实验记录或输入文件。
不传 `--factor-report` 时输出完整 JSON；传入时保存完整结果、终端只输出摘要。

## 数据契约与成交模式

每行代表某个历史日期的一只股票：

| 字段 | 用途 |
| --- | --- |
| `code,date,open,high,low,close,volume` | 必需；按每只股票日期递增、同日同股唯一。量价口径应一致；OHLC 为正、量非负。复权量价用于技术特征及研究收益标签。 |
| `eligible` | 可选逐日布尔值：该日是否属于历史研究股票池；没有时全部输入股票视作成员，并提示幸存者偏差。 |
| `raw_open,raw_close` | 严格成交需要的未复权价格。同一股票必须成对且全时段完整，不能与复权价交替使用。 |
| `tradable` | 严格成交需要的历史可交易状态；布尔或 0/1，不接受字符串。 |
| `limit_up,limit_down` | 严格成交需要的当日实际涨跌停价格；不可用复权价推算替代。 |
| `industry,market_cap` | 开启中性化时必须有逐日历史行业、市值；不能用今天的数据回填。 |
| `source` | 可选数据来源，报告汇总并保留输入指纹；字段本身不证明来源可靠。 |
| `corporate_action` | 可选公司行动标记；出现 true 时拒绝研究，因为本版没有分红送转账务。 |

默认 `--factor-execution strict`：缺少信号日原始收盘价，或执行日缺少原始价、状态、涨跌停价时阻止成交。输出 `incomplete_execution_metadata`，保留诊断报告，CLI 返回非零退出码。

已有 `k_daily` 通常只有复权行情，不具备全部成交元数据。需要明确接受粗略成交估计时可增加：

```bash
--factor-execution research
```

此模式缺少原始价时使用复权价，缺少涨跌停价时按前一已知收盘价的 ±10% 估算，报告明确标注近似。这不适用于 ST、上市初期、除权等特殊情形。
本版限制为普通 A 股主板代码，不覆盖创业板、科创板、北交所或指数交易。

停牌/零量行不产生新因子。缺失整行的股票不参与当天排名；存量持仓保留最后已知收盘估值并记录 `stale_marks`，不把它自动当作可以卖出。存在旧价估值时报告为 `incomplete_valuation`，不能据此宣布收益验证通过。

## 因子与融合

复用 14 个量价特征：5/10/20 日收益、相对 MA5/20/60、布林带宽度、相对 ATR、20 日波动率、量比、RSI 及 3 个相对 MACD 指标。

每个日期独立对横截面进行 1%/99% 分位裁剪和秩标准化，不用未来均值或全样本拟合的标准化器。
开启 `--factor-neutralize` 后，先对行业哑变量和 log(市值) 做当日残差化，再转成中心化秩；这会减少这些暴露，但转秩后不保证严格线性正交。横截面自由度不足时该日不可用。

每个训练窗只使用标签已在验证首日前实现的样本，检查：

- 标准化因子的每日 Pearson IC 和 RankIC；
- RankIC 均值、未年化 ICIR、方向一致比例及前后半段符号一致性；
- 五分组平均未来收益、最高组减最低组收益；
- 训练段因子相关性，剔除高度相关的重复因子。

默认至少 30 个有效 IC 日、平均绝对 RankIC ≥ 0.02、方向一致比例 ≥ 55%、前后半段同向，绝对相关性 ≥ 0.85 时去冗余，最多保留 5 个因子。这些是可复现的研究筛选门槛，不是经过独立验证的最优参数或显著性标准。

`--factor-fusion ic_weighted` 用训练平均 RankIC 的符号与大小融合，绝对权重之和为 1。
`--factor-fusion equal` 只用训练期确定方向，所选因子按绝对值等权。
没有有效因子时目标为空、尝试退出持仓；不回退到随意选股。卖不出去的仓位仍保留。

## 时间隔离与组合执行

默认训练 250 个面板交易日，验证 60 日，再滚动到下一个窗口。
收益标签为 **t+1 开盘到 t+1+N 开盘** 的收益，N 为调仓间隔（默认 5 日）。训练标签结束日期须严格早于验证首日，尾部 N+1 个候选日因而被隔离。

验证期排名只依赖当日因子和已冻结训练权重，不因未来行情或标签缺失提前删除股票。
每 N 个面板交易日选排名前 K 只，目标等权。CLI 单股目标权重上限 20%，K 小于 5 时自然保留部分现金。实际权重会受价格跳空、整手和受阻订单影响，目标权重不是每天收盘强制上限。

全部股票共享一份账本：

- 在信号日收盘的净值和原始收盘价上确定目标股数，下一开盘按模拟成交价格执行；不以当天收盘或全天成交量决定开盘订单大小。
- 先卖后买，按 100 股整手处理；支持减仓、加仓和逐批持仓 T+1。
- 佣金默认单边 0.03%、每笔最低 5 元；卖出印花税 0.05%、单边滑点 0.1%。费用在每次成交时扣除，现金不足则减量或阻断。
- 涨停阻买、跌停阻卖；开盘价或滑点价越过价格限制时不成交。不假设集合竞价一定能排到成交。
- 未成交目标逐日重试，到下一次调仓时被新目标覆盖。退出受阻的仓位占用现金和持仓名额，不虚构资金释放。
- 各窗口共用连续账本。期末按市值估值，保留未平持仓，不强制制造期末卖出。

等权对照使用相同的当日有效股票池、起止日期、调仓时点、费用和执行约束，但持有整个有效池；另给出现金收益 0。它是等权研究组合，不是市场指数。

## 报告与下一窗口反馈

完整 JSON 包含：

| 字段 | 内容 |
| --- | --- |
| `coverage,sources,input_sha256` | 股票覆盖、来源标记与输入指纹 |
| `folds[].fusion` | 训练期因子诊断、剔除原因、所选相关性矩阵及权重 |
| `folds[].oos_*_diagnostics` | 验证期单因子及融合因子的检验结果，不能回头参与本折筛选 |
| `folds[].strategy_net/equal_weight_net` | 从连续净值曲线切片得出的分窗口表现，不重置账户 |
| `selections` | 每次调仓的排名、目标权重和空仓原因 |
| `strategy/equal_weight_benchmark` | 每笔成交及费用、阻断原因、每日现金/持仓/净值、回撤、Sharpe、换手、期末持仓 |
| `validation_summary` | 有效因子窗口数、超额为正窗口数；不是自动晋级评分 |
| `missing_metadata,execution_status,warnings` | 数据与模拟边界，不把无成交或旧价估值掩盖为有效业绩 |

下一训练窗口可使用已经实现收益的过去验证样本重新评估因子方向和权重，这是 walk-forward 的反馈环；未实现标签始终不可用。代码不会读取整段 OOS 后再修改早期结果。

## 当前验收边界

离线合成数据测试验证因果性、筛选隔离、连续账本、费用/T+1/整手、受阻执行和只读 CLI。
合成数据构造了易辨识规律，只用于检验代码，不是市场盈利证据。

真实数据验收仍需：历史股票池及退市样本、准确复权和交易日历、公司行动账务、可执行行情、独立最终留出区间及后续模拟盘观察。日历暂用输入面板日期的并集，若所有股票同一天缺记录，需要外部交易日历审计才能发现。
多日标签重叠，ICIR 不作为独立样本 t 检验；反复看 OOS 后挑因子和门槛仍会导致过拟合。

本功能不改变现有调度或交易链路。回滚只需停止使用该命令；保留独立 JSON 报告供对比。尚无策略自动晋级机制，所有报告 `promotion_allowed=false`。

```bash
python scripts/run_tests.py --run-one tests/test_factor_research.py
python scripts/run_tests.py --run-one tests/test_ml_baseline.py
python scripts/run_tests.py --run-one tests/test_backtest_integrity.py
```
