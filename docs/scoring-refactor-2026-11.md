### 2.3 结论

- `DECISION_MIN_BUY_TECHNICAL=58` 选出的是系统性跑输的股票。技术分越高，后续越差，与 10-29 文档中“趋势/动量因子 IC 为负”的结论一致。

- 综合分里能历史重放的只有技术分（35% 权重）。其余维度中：
  - 情绪面是全市场同值，不区分个股。
  - 舆情面在线上样本中 IC 为 -0.10。
  - 资金、基本面、ML 在线上样本中 IC 约为 0。
  
  现有六维加权综合分没有可证明的优势，不应再作为买入依据。

## 3. 第 1 步：替换候选来源与打分（待确认）

不新写打分器，复用已影子运行的 `strategy/style_pools.py`。它的候选池按收盘数据每日生成，因子权重由滚动 IC 决定，回测见 10-29 文档 §9。

改动：

1. 新增配置 `CANDIDATE_SOURCE=legacy|style_pools`，默认 `legacy`，切换可回滚。
2. `style_pools` 模式下，盘中扫描读取最近一个收盘日 `data/style_shadow.db` 的候选，例如超跌反弹、低波防守、因子分前列，合计 30–50 只。每只候选携带风格标签和因子分（0–100 横截面百分位）。
3. 准入改为“因子分排名前 N% + 风格池成员”，去掉 `DECISION_MIN_BUY_TECHNICAL` 和绝对 `min_score` 两道门槛。旧六维分只作为记录，不参与准入。
4. 两轮稳定性确认对日频因子没有意义（因子分盘中不变），在该模式下关闭。
5. 实时价校验、一手可买、价格漂移、T+1、熔断、止损等执行层风控全部保持不变。

需要确认的取舍：

- **大盘仓位上限。** 回测中“超跌反弹 + 大盘上限”最好：年化 +2.8%、回撤 -17.6%。但当前上限为 0，照搬就仍然不交易。
  - 可选 A：严格照搬，等上限打开再交易。
  - 可选 B：上限在模拟盘先只做记录，实际按固定小仓位（单票 3–5%、总仓位 ≤30%）交易，以更快积累前向证据。不加上限时，超跌反弹 2022-2026 年化为 -3.6%，等权为 -5.3%。在熊市里大概率仍是亏损，只是比全市场少亏。
- **提前切换。** 原晋级门槛要求 20 个 5 日成熟信号日，约 12 月上旬。模拟盘可以先切换、同时保留影子对比；也可以继续等。

## 4. 第 2 步：LLM 改为否决层（待确认）

- 默认执行量化候选；LLM 只能以固定类别否决：停牌/复牌风险、一字涨停不可成交、重大利空公告、监管/退市风险、数据异常。否决必须给出类别和证据，不能用自由文本理由。
- 提示词提供：
  - 风格标签、因子分与排名、已通过的准入条件
  - 实时价、涨跌停价、手续费与仓位预算
  - 明确声明：未提供的数据（盘口、分时、资金流）不构成否决理由
- 移出交易员提示词的内容：复盘的自由文本（`style_plan.focus/invalidate_when`）、历史 HOLD 理由回放、“近期优化建议”。
- 输出：`{"veto": bool, "category": enum, "evidence": str, "confidence": 0-1}`。LLM 超时或解析失败按“不否决”处理还是“否决”处理，需要确认：前者让量化信号说了算，后者更保守。
- 每次否决记录被否决标的的事后收益，按类别统计，与“不否决直接买”对比，证明这一层是否有价值。

## 5. 第 3 步：复盘循环（待确认）

- 复盘 LLM 不再读取自己前一天的完整指令（`hypothesis`、`style_plan` 原文），只读结构化参数与当日事实。
- `daily_facts` 增加按 `hold_reason` 前缀的分门槛计数；`_denial_layer` 补全 `tech_gate`、`stability_gate`、`min_lot`、`signal_quote`、`stale_directive`。
- 复盘只能在代码给定的枚举与范围内调整：风险档位、风格偏好、总仓位上限。准入阈值由影子与回测证据规则驱动，不交给 LLM。

## 7. 实施记录（2026-11-05）

已确认的取舍：

- 大盘仓位上限只记录、不执行（可选 B）。
- 不等晋级门槛，提前切换。

### 7.1 行为（`CANDIDATE_SOURCE=style_pools`）

| 环节 | 旧路径（legacy） | 风格池模式 |
|---|---|---|
| 候选来源 | `pick_stocks(top_n=10)` 事件列表 | 上一交易日收盘的风格池：超跌反弹、低波防守、因子分前列，约 40 只；剔除名称含 ST/退 |
| 风格池日期 | — | 必须等于上一交易日，否则本轮不开新仓（`HOLD`，`plan.errors` 写明原因） |
| 打分 | 六维加权综合分 | 横截面因子分（0–100 百分位），不再计算舆情/资金/基本面/ML |
| 准入 | 技术分≥58、综合分≥min_score、连续两轮确认 | 入池即可（`STYLE_MIN_FACTOR_SCORE` 默认 0）；按风格名额加权轮转、风格内按入池排名，取前 `STYLE_MAX_VETO_REVIEWS`(6) 只（见 §8） |
| 确定性预检 | — | 已持有、实时行情缺失、涨停（主板 10%/创业板 20%）、一手买不起，均不送 LLM |
| LLM | 逐只审批，默认 HOLD | 只做否决（`strategy/llm_veto.py`），固定类别，失败即否决；同日同股明确结论复用 |
| 仓位 | `max_weight×综合分/100` | 固定 `STYLE_POSITION_WEIGHT`(5%)，不随熊市指令 max_weight/top_k 缩减；总仓位≤`STYLE_MAX_TOTAL_EXPOSURE`(60%)，持仓数≤`MAX_POSITIONS`，每日新开仓≤`STYLE_MAX_DAILY_BUYS`(3) |
| 卖出 | LLM 逐只判断 | 持有满 N 个交易日按期卖出，N 取自 `data/style_allocation.json`（初始 `STYLE_HOLD_DAYS`=10）；止损/止盈/移动止损不变 |
| 救援扫描 / 可转债扫描 | 运行 | 停用 |

执行层风控（实时价校验、价格漂移 ±3%、一手、T+1、熔断、系统风控、最低买入额）全部保持不变。

否决类别：`suspension`（停牌）、`untradable_limit`（封板不可成交）、`negative_announcement`（重大利空公告）、`delisting_risk`（退市/ST 风险）、`major_shareholder_exit`（大比例减持/冻结）、`data_anomaly`（材料矛盾）。否决复核的输入只有：
- 风格标签与因子分
- 已通过的准入条件
- 实时价、昨收、涨停价
- 仓位与手续费
- 个股近期新闻标题（标注为不可信外部数据）

不注入复盘自由文本、历史 HOLD 理由或“优化建议”。

新增拒绝原因：

| 原因 | denial_layer |
|---|---|
| `HOLD_FACTOR_LOW` | `score_gate` |
| `HOLD_LLM_VETO` | `llm` |
| `HOLD_VETO_UNAVAILABLE` | `llm` |
| `HOLD_NOT_TOP6` | `ranking_gate` |
| `HOLD_ALREADY_HELD` | `hold_unknown` |
| `HOLD_LIMIT_UP` | `hold_unknown` |
| `HOLD_EXPOSURE_CAP` | `hold_unknown` |
| `HOLD_STYLE_HOLDING` | `hold_unknown` |
| `HOLD_BUY_BUDGET(今日已开…)` | 与旧路径同名原因一致 |

否决复核写入 `llm_decisions`：通过记为 `BUY`，否决与失败记为 `HOLD`。因此看板漏斗里的“LLM 判断”和“BUY 信号”继续可用。

### 7.3 已知差异与风险

- 回测是“每 20 日等权调仓 15 只”，实盘是“每日最多买 3 只、最多 12 只持仓、持有 N 日或触发止损/止盈退出”，组合口径不同，收益不会与回测一致。
- 已修复：最初按因子分全局排序，因子分前列池（99–100 分）永远排在前面，其他风格轮不到；现改为按风格名额轮转（§8）。
- 大盘仓位上限当前为 0 但不执行：熊市里大概率仍是亏损，只是预期少于全市场等权。
- 风格池由 18:30 的 `alpha-pilot-style-shadow` 生成；该任务失败时次日不开新仓（不会回退到旧路径）。

## 8. 积极模式与学习闭环（2026-11-05）

目标：在模拟盘上多交易、积累样本，再按证据逐步调整，而不是靠层层门槛规避交易。

### 8.1 积极模式

- 单票 5%，最多 12 只，总仓位 ≤60%，每日新开仓 ≤3 只（约 4 个交易日建满，到期日错开）。
- 熊市不限制开仓：风格池模式不再使用指令的 `max_weight`/`top_k`。指令仍需当日有效，否则不开新仓。
- 保留：止损 -8%、回撤熔断 -15%、单日亏损 -5% 停新仓、系统风控仓位缩放、执行层价格校验。
- LLM 只拦固定类别的硬风险，失败即否决（不变）。

### 8.2 风格名额

`data/style_allocation.json` 中的 `slots` 是各风格名额（默认 12 个均分，即 4/4/4）。每轮送复核的候选按“已选数/名额”最小的风格优先轮转；风格内按入池排名。某风格候选用完后，剩余机会自动给其他风格。同一只股票属于多个风格时只计一次，`selected_style` 记录归属。

### 8.3 自动调整（`strategy/style_allocator.py`）

每天 18:30/20:30 风格池生成成功后执行检查；距上次检查不足 5 个交易日跳过。证据来自 `style_shadow.evaluate`，即近 120 个自然日内全部入池股票的扣费前瞻收益，不是模拟盘成交。每次最多改一项：

1. 名额：在当前持有期口径下，比较各风格的超额收益。最好与最差的风格都需有 ≥10 个成熟信号日，且差距 ≥0.3 个百分点；满足时从最差风格挪 1 个名额给最好风格。每个风格至少保留 1 个名额。
2. 持有期：名额不动时，比较 5/10/20 日档按名额加权的日均净收益。相邻一档高出 ≥0.03 个百分点/日时，移动一档。

每次检查（含“维持不变”）都通过 Telegram 推送报告（`AUTO_NOTIFY_ENABLED=1` 时）。通知失败不回滚调整。

### 8.4 为什么不用模拟盘盈亏做依据

12 只持仓、10 日持有，一个月只有约 25 笔成交。噪声远大于风格差异，而且止损/止盈会截断收益分布。影子评估每个信号日约有 40 只样本，口径与回测一致。模拟盘成交用于核对执行偏差（滑点、涨停买不到、止损频率），不直接驱动调参。

### 8.5 上线

在服务器 `~/.hermes/.env` 中设置：

```bash
CANDIDATE_SOURCE=style_pools
MAX_POSITIONS=12
```

然后执行 `systemctl --user restart alpha-pilot-auto.service`。首次检查发生在下一次风格池生成之后。

  - `signal_detail` 中 `via=` 覆盖多个风格；
  - `hold_reason` 中出现 `HOLD_BUY_BUDGET(今日已开3/上限3)` 而不是 `HOLD_EXPOSURE_CAP`。

### 8.7 回滚
